# Security

This repository is public.

Do not commit:

- passwords;
- API keys;
- tokens;
- private keys;
- real connection strings;
- customer data;
- protected business data;
- full OBM source code;
- raw OAuth secrets;
- raw database credentials.

Use placeholders for sensitive values, such as `<REDACTED>`, `<SECRET_FROM_LOCAL_STORE>`, or `<LOCAL_PATH_NOT_COMMITTED>`.

Reports, prompts, handoffs, manifests, and diagrams must be safe for public review before commit.
