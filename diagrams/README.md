# Diagrams

Store versioned Mermaid diagrams here.

Naming convention:

Use explicit version folders and descriptive Mermaid filenames, such as:

`diagrams/v001/coordination-flow.mmd`

Related artifact naming conventions:

- Prompt: `PROMPT-<sequence>-<task-slug>-v<version>.json`
- Report: `REPORT-<sequence>-<task-slug>-v<version>.json`
- Handoff: `HANDOFF-<sequence>-<task-slug>-v<version>.md`

Do not overwrite an existing version. Create a new numbered or versioned artifact instead.
