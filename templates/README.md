# Coordination Templates

Use these templates to keep ChatGPT, Cursor, and Codex interoperable.

- [`TASK_TEMPLATE.md`](TASK_TEMPLATE.md) — complete task packet.
- [`REPORT_TEMPLATE.md`](REPORT_TEMPLATE.md) — implementation and evidence report.
- [`INVESTIGATION_TEMPLATE.md`](INVESTIGATION_TEMPLATE.md) — reusable read-only findings.
- [`MODULE_CONTEXT_TEMPLATE.md`](MODULE_CONTEXT_TEMPLATE.md) — durable module map.
- [`GRAPH_DELTA_TEMPLATE.md`](GRAPH_DELTA_TEMPLATE.md) — meaningful Graphify changes.

Copy a template into a numbered/versioned destination. Never edit a historical completed artifact merely to match a newer template.
